# isekai-playbook7

劇本 2：孤獨異世界。廢柴技能、一個人、365 天後魔王（BP 99）復活。
設計筆記在 Claude Project「RPG设计」（`異世界RPG_單刷框架清單.md`、`…劇本2_定案_1110.md`、`…劇本2_開工規格_1110.md`）。

## 檔案
- `game.js` 規則與狀態（不碰網頁，可在 node 跑）
- `ui.js` 畫面、存檔、選擇性的 Gemini 旁白（不填金鑰也能玩）
- `sim.js` 機器人玩家：`node sim.js 30`，看 365 天夠不夠
- `index.html` `style.css`

## 目前玩法（v0.1）
採集／狩獵／製作／整合／交易／進化／蓋與升級據點。判定比照魔物篇：淨優勢決定要付幾項代價（受傷、MP、時間、材料），付夠成功、再多一項大成功。
每次蓋或升據點立刻被襲擊（關鍵戰：優勢封頂 0，失敗＝據點毀，可逃回 F 重來或死亡）。365 天後魔王戰。
技能每天每個 3 次且耗 MP 1；魔法物品每天 1 次。開場「孤獨」：不組隊、交易價 ×2、D 級據點起才能交易。

## 規則
所有 .js 共用全域，不用 import/export；介面繁體中文；改完跑 `node --check`；不放金鑰。
