# isekai-playbook7

劇本 2：孤獨異世界。3 個隨機廢柴技能、一個人、365 天後魔王（BP 99）復活。
設計筆記在 Claude Project「RPG设计」（`異世界RPG_開局求生與F級據點_1110.md`、`…技能欄與組合規則_1110.md`、`…人類篇技能來源_1110.md`、`…偷學_天生替換_1110.md`）。

## 檔案（全域共用，照這個順序載入：data → game → world → ai → ui）
- `data.js` 內容表：廢柴技能池、地點、魔物與技巧、組合正解表、配方、管理員文字
- `game.js` 規則與狀態（不碰網頁，可在 node 跑）
- `world.js` 裝備、魔法物品、相剋、藥水、村落、地城、迷宮、敵對據點（v0.4）
- `ai.js` 自由敘事。呼叫模型的部分照搬魔物篇（免費模型自動挑選、Gemini＋OpenRouter 備援），設定頁也照搬，金鑰和魔物篇共用（同一個網址）。AI 只把玩家的話翻成行動清單、再依結果寫故事，不改數字
- `ui.js` 畫面、存檔、自由敘事流程
- `sim.js` 機器人玩家：`node sim.js 200`，看第一章要幾天
- `sim365.js` 機器人打到 365 天：`node sim365.js 30`（加 `shesh` 快被攻破就捨身、`dbg` 印出第一局每一場升級戰的判定）
- `index.html` `style.css`

## v0.2 玩法
- **第一章・求生**：食物、火、水、避難所四項打勾就完成，接著選要不要在這裡建立據點（第二章）。
  - 飢餓：睡覺 HP 只回到一半。沒有火：夜裡會冷、吃生肉可能生病。沒水：口渴 3 天死亡。
- **自由敘事**：在輸入框打一句話，AI 讀懂成行動（採集、探索、狩獵、戰鬥、撤退、製作、組合、移動……），程式判定。沒設定 AI 也能用按鈕玩。
- **判定**：淨優勢決定要付幾項代價（受傷、MP、時間、材料）；捨身＝拿一處傷殘（HP 上限 −2）換大成功。撤退也要付代價。
- **組合（靈光一閃）**：最多 3 個技能＋對象（地點、物品、看過的魔物技巧、眼前的敵人）＋手法。MP＝技能數，每個技能扣一次當天次數。
  - 失敗：碎片。成功：組合正確就學會技能，不正確給碎片。大成功：再多一片碎片。
  - 碎片：3 片同大類 → 同大類三選一；10 片任意 → 任意三選一。
- **偷學**：遭遇魔物時記下牠的技巧（永久）。人類學不走天生部位，用自己的方式替換（看了風爪 → 風刃、風附魔……），每個技巧先學一個版本。
- **技能表 9 格**、每個技能一天 3 次；倉庫 F 20、E 25、D 30、C 35、B 40、A·S 50；交換花 1 小時。整合：3 個同大類同階 → 高一階。
- 遭遇的魔物最高比你高 3 級。
- **第二章・據點**（v0.3.1）：
  - 捐物資換點數（一般 1、獸皮 2、魔核 4、物品 3），點數升級據點：E 20、D 80、C 250、B 500、A 900、S 1500。
  - 每升一級打一場升級戰（主角的異香引來大軍）。F→E：C 級個體 5 回合；E→D：1 隻 B＋3 場軍隊；D→C：3 B＋3 軍；C→B：2 B 1 A＋3 軍；B→A：3 A＋3 軍；A→S：3 S＋3 軍。輸掉一半或 HP 歸零＝被攻破；中途逃走＝放棄據點。被攻破或放棄後選「搬家」或「陣亡」：搬家只能去還沒當過據點的地方（設施全毀、F 級重來、物資剩一半），沒地方可搬就只能陣亡。升級前會先跳確認，列出要來的對手和你的狀態。升級戰頭目的技巧學不來。
  - 多打一劣勢（data.js `ARMY_DIS`）：軍隊 D 6.5、C 7.2、B 8.3、A 9.3、S 10 條（小數＝有時多 1 條），魔物個體少 1 條；每座在運作的設施擋 1 條，柵欄多擋。
  - 升級戰是關鍵戰：不能付時間，物品一場最多一件（武器、藥；不會用掉防具和背包）。捨身一場升級戰只能一次。背包 8 件（有背包 12）。
  - 設施：每升一級三選一（暫定：農田、修練場、柵欄、望樓、鍛冶台、藥草園），放一個技能進去才運作。
  - 第 365 天後：魔王戰 7 場（六個方位各一支軍團＋一隻 S 級魔物，最後魔王），輸 4 場或輸給魔王就結束，逃不掉。
- **捨身**：選一個部位受傷換大成功，可以重複受傷。眼睛：探索時間加倍；單手：製作、組合時間加倍；腿：移動時間加倍；身體：HP 上限 −20%、睡覺回不滿；心靈：MP 上限 −1、睡覺回不滿。據點 S 級後開發萬靈藥（魔核 5、草 5），一瓶治好一處。
- **結局**：打贏魔王時捨身傷 3 處以上＝壞結局「收藏品」（身體廢了、被世人遺忘、管理員給你收藏櫃的一個位置）；否則退休。
- 存在值滿了自動進化（HP、MP 回滿），多的帶到下一級。天生碎片三選一從看過、還沒偷學的魔物技巧裡抽；某一類抽光了用別類補滿 3 個。
- 存在值門檻：F 10、E 40、D 90、C 150、B 220、A 300。打倒魔物、守住升級戰的每一場、學會技能、找到新地點、第一章完成都加。

## v0.4（用戶 11-11 設計清單，見 Project《異世界RPG_設計清單_1111_地點魔物裝備》）
- **屬性兩層**：元素 火水土風木光暗（相剋用）；性質 切割重量硬化包覆聲音移動感知魔力。冷／冰＝水、熱＝火、草＝木、雷＝風、毒＝暗。
- **相剋 +1**：水→火→木→土→風→水，光暗互剋，切割剋包覆、重量剋硬化。普通遭遇、升級戰、魔王戰都算。
- **裝備欄**：頭、項鍊、戒指、武器（單手／雙手近戰／單手遠程／雙手遠程）、副手（盾配單手近戰；箭矢袋／石袋配遠程，不做彈藥）、衣服、鞋子。武器 +1、遠程再 +1；近戰打遠程對手多付 1 項；雙手近戰大成功少付 1 項；盾／衣服／頭減傷。比對手等級低的裝備用完就壞。
- **魔法物品**：一個效果（附帶技能不扣 MP、屬性、抗性、HP／MP 上限、移動減半、飛行、傳送、採集減半），一天 3 次；當代價一場付 1 次，同一場第 2 次就壞。來源：鍛冶台 4 天 1 件、地城、迷宮、敵對據點、升級戰獎勵、村落。
- **代價自選**：判定卡上自己選付哪一件（材料、背包、身上的）。壞掉、丟失都不能修。
- **藥水**：草藥膏 HP 25%、紅 HP 50%、藍 MP 50%、紫各 25%（進位）。戰鬥中能喝，敵人照樣打你一下。
- **地點 30 個**：野外 15、地城、迷宮、村落 6（人類、半身人、精靈、矮人、亞人、人魚）、敵對據點 7。探索看等級：F～E 近、D～C 中、B 以上遠。魔物 45 種，遭遇從地點的魔物表抽。
- **村落**：友好度最多中立；送禮、學語言、買專屬技能（人類戰技、精靈魔法、矮人符文、半身人詩篇、亞人陷阱、法術封禁），放進對應設施加強，升級戰剋對應軍隊。
- **敵對據點**突襲、打下可佔領當據點；**地城**一層一層、寶箱魔法物品；**迷宮** 1～7 層可以一直刷。
- 望樓改名**哨塔**。多打一劣勢重調：D 7.8、C 7.0、B 8.0、A 8.3、S 8.5。
